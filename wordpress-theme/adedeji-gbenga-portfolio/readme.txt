=== Adedeji Gbenga Portfolio ===

Setup after activating the theme:

1. Go to Pages > Add New. Title it "Resume", set the URL slug to
   "resume".
2. In the Page Attributes panel, set Template to "Resume Page".
3. Publish the page.

This makes the Resume links in the nav bar, hero, and footer work,
and gives you the printable /resume/ page.

No other setup is required — the homepage (hero, about, skills,
experience, projects, contact) renders automatically from index.php.
